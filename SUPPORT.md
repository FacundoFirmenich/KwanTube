# Support

## How to get help

- Usage questions and troubleshooting: open a GitHub Issue.
- Bug reports: open a GitHub Issue with reproduction steps.
- Security concerns: follow private reporting in `SECURITY.md`.

## What to include

- OS and Python version,
- install method,
- command executed,
- error output,
- expected vs observed behavior.

## Reproducibility support

For reproduction help, include:

- exact command(s),
- random seed(s),
- artifact paths generated,
- commit/tag used.

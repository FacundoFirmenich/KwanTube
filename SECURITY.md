# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for suspected vulnerabilities.

Instead, report privately to the maintainers with:

- affected component/path,
- reproduction details,
- potential impact,
- suggested mitigation (if available).

## Response targets

- Initial acknowledgement: within 72 hours.
- Triage decision: within 7 days.
- Fix timeline: depends on severity and reproducibility impact.

## Disclosure policy

- We coordinate disclosure after a fix is available.
- Credit is given to reporters who choose to be acknowledged.

## Scope notes

- Numerical integrity issues that alter scientific conclusions are treated as high severity.
- Reproducibility-breaking bugs are prioritized.
